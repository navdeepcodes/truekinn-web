# TrueKinn — Web

Marketing site for TrueKinn, a private, college-focused community platform
(18+).

## Stack

- [Next.js](https://nextjs.org) (App Router) + React + TypeScript

## Structure

```
app/
  layout.tsx
  page.tsx
```

Single landing page today.

`child-safety.md` — TrueKinn's zero-tolerance CSAE policy. Legal pages
(privacy policy, account deletion) live in the separate
[`public-policies`](https://github.com/navdeepcodes/public-policies) repo.

## Running locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run build
npm run lint
```
